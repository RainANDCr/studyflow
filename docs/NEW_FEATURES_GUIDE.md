# 五大新功能指南（NEW_FEATURES_GUIDE）

> 本指南介绍 2026-10 增量加入的五项功能与统一数据口径。全部离线本地运行，无任何云端依赖。

## 1. 智能学习日历

**入口**：今日页右上角「日历视图」（二级视图，不占主 Tab）。

- **月 / 周视图**：周一起始；格子显示每日计划量 chips（目标色点 + 数量，绿底划线 = 已达成）与纯打卡日的实际量。
- **日详情抽屉**：点击任意日期 → 按目标列出「当日计划 / 当日实际 / 剩余计划」与目标截止日；操作：直接打卡、调整计划量（转手动）、更改日期（手机/键盘等价于桌面拖拽）、该日不安排（删除计划 + 写入排除日）。
- **拖拽改期**（桌面）：拖动计划条到另一格 → 确认「源日期 → 目标日期」→ 落库后转为手动安排；失败原值保留并报错。
- **自动排程**：选择目标 → 商/余数把剩余量分摊到截止日（含当日）；预览「更新/新增/移除/不变/手动让位」后确认，单事务写入。**手动安排与历史日期永不覆盖**。
- **计划设置**（抽屉内按目标）：学习星期、排除日期、每日上限。与「每周弹性休息日」是两套独立规则。
- **口径**：计划 = 准备做什么；实际完成只由打卡决定。「今日建议量」（旧推荐算法）与「当日安排量」（日历）并存且明确区分。

## 2. 目标拆分与里程碑

**入口**：看板目标卡内「阶段计划 / 里程碑」折叠区。

- 有序阶段（上移/下移排序）：标题、计划量、可选起止日期；展示进度条、完成徽标、逾期天数、下一阶段定位。
- **三种拆分入口**（全本地计算）：手动录入 / 平均拆分（商余数保证 Σ阶段量 = 待拆余量）/ 按时间分段。阶段总量超出主目标总量时显式警告，绝不静默缩放。
- **打卡关联阶段**：打卡弹窗可预选当前阶段（默认第一个未完成阶段），可改选或不关联。
- **口径铁律**：主目标完成量 = Σ该目标全部打卡（无论是否关联）；阶段进度 = Σ指向该阶段的打卡；**勾选小步骤不改变任何量化进度**（步骤是纯清单，独立完成率）。
- **未分配区**：旧打卡/未选阶段的记录显示数量，可一键批量关联某阶段；删除阶段时打卡保留并回到未分配，主目标进度/连续/周报全部不变。

## 3. 番茄钟专注模式

**入口**：今日页「开始专注」。

- 关联目标（可选）与阶段；时长预设 25/5、15/3、50/10、自定义（1–240 分钟）。
- 大号环形倒计时；开始/暂停/继续/提前结束/放弃；完成有克制动效与可选浏览器通知（权限不支持则页面提示）。
- **计时真相**：以 `Date.now` 差值 + 持久化状态计算（interval 只刷 UI）；暂停冻结快照、恢复平移起点；刷新/重启后提供「继续 / 保存已完成部分 / 放弃」恢复；系统时钟异常钳制，不产生夸大值。
- **结果确认**（不自动虚构）：只保存专注记录（合法），或「同时打卡」需如实填写数量（必填），分钟预填有效专注分钟（可改）；二者建立关联。
- **去重口径**（全应用统一）：有效学习分钟 = ① 明确填写的打卡分钟 + ② **未关联打卡**的会话分钟（跨午夜按本地日历日拆分）；已关联的经打卡分钟统计一次，绝不双计。周报、14 天图、热力图共用同一函数。
- 休息时长永不计入学习投入分钟。

## 4. 学习数据热力图

**入口**：看板页下方「年度学习热力图」（近 12 个月 / 365 天，标题标注口径）。

- 列 = 周（周一起始）、行 = 周一至周日；5 档紫色梯度 + 图例文本标签（0 表示无已记录活动，≠ 一定没学习）。
- 双口径切换：**有效分钟**（统一去重口径）/ **打卡活跃度**（每日打卡条数）；支持全部/单目标筛选。
- 悬停 tooltip 显示日期、打卡次数、有效分钟、主要目标；点击格子打开该日详情（与日历共用抽屉）；未来日期不可点击。
- 手机横向滚动；与 14 天分钟堆叠图数值口径一致。

## 5. 计划模拟器

**入口**：看板目标卡「模拟」按钮。

- 显示总量/已完成/剩余/截止/近 7 天**实测**速度预测（不足 3 活跃日显示「暂无推算」）。
- 可调参数：每学习日完成量（滑块+输入）、学习星期、排除日期；**保守 / 当前设定 / 激进**三组预设，全部明确标注为「假设情景」，非 AI 预测。
- 实时输出：模拟完成日（与截止日比提前/拖后/按时）、所需学习日数、截止前最低每学习日量；SVG 累计曲线（实线=真实历史、虚线=未来假设、红竖线=截止日）。
- **应用到计划**：预览 DailyPlan 变更数 → 确认 → 仅写未来日历计划；**不创建打卡、不修改截止日**；超出截止日建议先改截止日。
- 只填每日分钟不提供单位换算（缺少依据，明示原因）。

## 统一口径速查

| 数值 | 口径 |
|---|---|
| 主目标进度 | Σ 该目标全部 Checkin.amount |
| 阶段进度 | Σ 指向该 Milestone 的 Checkin.amount（与主进度独立，不重复） |
| 今日建议量 | ⌈剩余 ÷ 剩余天数⌉（旧算法，未变） |
| 当日安排量 | DailyPlan.plannedAmount（日历独立数值） |
| 连续天数/休息日 | 仅按真实打卡日期与旧逻辑，计划/专注不参与 |
| 实测预测 | 近 7 天真实打卡（≥3 活跃日） |
| 模拟完成日 | 用户假设推演（沙盘） |
| 有效学习分钟 | 打卡 minutes + 未关联打卡的 FocusSession 分钟（去重、跨午夜拆分） |
