## 方法学说明

- 业务函数全部接受注入的 `today`/`clock`，测试用固定日期（2026-03 周期：03-02 周一、03-09 周一、03-15 周日；闰日用 2024-02）覆盖周日/周一、跨月、跨年、闰日。
- 存储契约测试只跑了 IndexedDB 实现；SQLite 实现遵循同一接口契约，但需要 Tauri 原生运行时（WebView2 + Rust），**未在本机自动化验证**——属诚实标注的未验证项（验证步骤见 docs/BUILD_WINDOWS.md 第 4 节）。
- jsdom 受控输入驱动采用「原型 value setter 绕过 React value tracker + act() 包裹派发」的标准做法（测试文件内有注释说明）。
- 开发过程中测试抓出并修复的真实缺陷：预测提前/拖后方向写反；打卡弹窗 useEffect 依赖不稳定数组导致数据刷新清空用户输入。
