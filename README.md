# 📖 完整使用说明

## 一、第一次打开会发生什么

应用首次启动会自动写入 **3 个演示目标**（背英语单词、读《人类简史》、Python 入门课），全部带「示例」标记，让你一眼看到各功能长什么样。你随时可以去「我的 → 清空示例」一键删掉它们，**不会影响你自己创建的任何数据**。

界面分四个主标签（手机在底部、电脑在左侧）：**今日 / 看板 / 周报 / 我的**。右上角有两个小按钮：主题切换（深色 ↔ 浅色 ↔ 跟随系统）和 GitHub 仓库直达。

## 二、今日页 —— 每天打开看的地方

### 1. 创建第一个目标

点「新建学习目标」，填六样东西：

- **名称**：如「背考研单词」
- **单位**：任意自定义——词 / 页 / 节 / 题 / 小时……应用不预设学科
- **总量**：如 3000
- **开始日 / 截止日**：截止日不能早于开始日
- **主题色**：六色可选，用于图表区分
- **障碍与预案（可选）**：「最容易拦住我的障碍」+「如果它出现，我就……」（WOOP 心理学写法，写了对坚持很有用）

保存后，应用立刻算出**今日建议量** = 剩余量 ÷ 剩余天数（向上取整）。举例：3000 词还剩 2990、截止还有 58 天 → 今天建议背 52 个。

### 2. 打卡（一个目标一天可以打多次）

- 点目标卡上的「**立即打卡**」：数量已预填建议量（可改），分钟数**选填**，可写一句备注。
- **补记**：昨天忘了？打卡表单里「记录日期」可以选最近 6 天中的任何一天，补记的记录带「补」字小标，统计按你选的日期归属（连续天数、周报、图表全部按归属日重算）。
- **极速打卡**：目标卡上的「记 N 单位」按钮，一键按建议量保存，保存后出现「撤销」按钮，点一下就精确删除这一条（不碰同日其他记录）。
- **批量记录**：今日页顶部「批量记录」，一次录多行（日期 / 目标 / 数量 / 分钟 / 备注），可复制上一行；任何一行不合法会整批拒绝并指出问题，绝不半成功。

### 3. 目标卡上的数字都什么意思

- **今日建议 / 连续 N 天 / 预计完成日**：连续天数基于真实打卡；「预计完成日」来自你**近 7 天的实际速度**（至少 3 个有打卡的日子才显示，否则显示「暂无推算」——这是诚实，不是缺陷）。
- **黄卡**：昨天没打卡但自动用了本周弹性休息日（每周一次、不中断连续），提示「今天继续即可」。
- **红卡**：昨天缺卡且本周宽免已用完 → 连续中断，并给出「把剩余计划滚入今日」的建议量。它不会偷改你的历史记录。
- **逾期目标**：显示「已逾期 X 天」+ 两个出口（立即打卡 / 调整计划）。

### 4. 一键开始学习（番茄钟）

点目标卡「开始」直接进入专注模式（也可从今日页顶部「开始专注」进入后选目标）：

- 时长预设 **25/5、15/3、50/10** 或自定义（1–240 分钟），应用记住你上次的选择。
- 期间可暂停 / 继续 / 提前结束 / 放弃；**关掉页面、切后台、重启应用都不会丢计时**——回来时它会问「继续 / 保存已完成部分 / 放弃」。
- 计时结束**不会自动算你学了什么**（专注 25 分钟 ≠ 背了 50 个词）。结束时二选一：只保存专注记录，或勾选「同时创建打卡」并**如实填写完成量**。
- 专注与打卡的分钟统计**自动去重**：关联打卡的会话只按打卡里的分钟算一次。

### 5. 目标的生命周期

目标卡底部有状态操作，对应不同场景：

- **暂停**：考试周/出差时用。暂停期间不出现在待办里、不自动排程；历史全部保留；恢复时截止日**不会**被悄悄延长（会提醒你重新排程）。
- **取消**：主动放弃（不是删除），历史数据永远可查。
- **归档**：完成后的目标收纳起来，进度随时回看。
- 「已完成」不是手动状态——是打卡总量达到目标总量后**动态推导**的，你删除一条打卡它会自动变回进行中。

今日页顶部的筛选条可以在 进行中 / 已完成 / 已暂停 / 已取消 / 已归档 / 全部 之间切换。

## 三、看板页 —— 所有目标的仪表盘

- **每个目标一张大卡**：进度环、完成率、连续天数、预计完成日、障碍预案、最近 10 条打卡（可删除，删除后所有统计即时重算）。
- **双轨进度**：紫色是「内容完成率」（打卡量），绿色是「知识掌握覆盖率」——你为这个目标定义知识点并**真实自评**（0 完全不会 → 4 熟练迁移，5 档）后才有。没建知识点会显示「尚未建立知识点」，绝不假装 0%。支持批量粘贴添加知识点、按里程碑归属、归档、复习薄弱项。
- **里程碑**：把 440 页拆成「阶段 1/2/3」，可手动、平均拆分、按时间分段（拆完的量精确等于总量）；打卡时可关联到某个阶段；删除阶段不会删打卡。
- **计划模拟器**：目标卡上的「模拟」按钮——假设每天背 N 个、每周学哪几天，实时看模拟完成日和累计曲线（虚线是假设，实线是真实），满意的话可一键写入日历计划。
- **14 天分钟柱状图 + 年度热力图**：只统计明确填写的分钟（未填的打卡算活跃但不算分钟）；热力图支持 有效分钟 / 打卡活跃度 两种口径和按目标筛选，点格子看当天详情。
- **分析中心**：投入分钟、活跃天数、计划兑现率、单位时间产出（如「12 页/小时」）——按 7/30/90 天查看并环比；还有逐日「计划 vs 实际」对比表。

## 四、学习日历（今日页 → 日历视图）

- 月 / 周视图，格子里显示每天的计划量（绿底划线=已达成）和实际打卡。
- **自动排程**：选目标 → 应用把剩余量按「商/余数」精确分摊到截止日（不会丢量）；先预览「更新/新增/移除」清单再确认；你手动改过的计划带锁，重排永不覆盖。
- **拖拽改期**：桌面端拖动计划条到另一天（手机在日详情里「更改日期」）；每次重排都记录修订历史。
- **每天计划 vs 实际**：点任何一天看明细，可「调整计划量」「直接打卡」「该日不安排」。
- **时间预算**：设置周一到周日各自可用分钟（0=明确休息，留空=未设置）、特定日期例外（考试周、出行）；超出预算的日子有警示。
- **计划需要调整**：昨天计划没完成时，日历页顶部会出现提示卡（只提醒不自动改），点「重新排程」进入预览。

## 五、周报页 —— 复盘与长期报告

- **周报**：按周切换（不能看未来），分目标完成量（不同单位绝不混加）、与上周同口径环比（本周进行中只比到今天为止的部分）、投入分钟（含专注会话、自动去重）。四栏复盘：**保持 / 问题 / 尝试 / 下周预案**，保存后永久保留。一键生成可复制的中文周报文本。
- **长期报告**：月报 / 季报 / 年报——活跃天数、投入分钟、分目标完成量、计划兑现率，配四项复盘（本期收获/最大困难/调整方法/下期计划），可**保存快照**（之后数据变了也不影响已存版本）并复制 Markdown。
- 所有报告只陈述真实数据：没有记录就写「暂无」，绝不编造进步。

## 六、考试冲刺模式（今日页 → 考试冲刺）

1. **建考试**：名称 + 考试日期（倒计时：考试日当天=0，已过显示「已结束 N 天」）。
2. **关联目标**：一个考试可关联多个已有目标并设优先权重（只是建立关系，不复制数据）。
3. **备考阶段**：一键生成「基础→强化→冲刺→回顾」草案（可完全自定义），阶段日期互不重叠。
4. **可用时间**：按星期设置每天能学多少分钟，指定日期可覆盖（如休息日设 0）。
5. **生成冲刺计划**：按权重把每天可用分钟分给各目标，生成前预览；你手动锁定的安排永远保留；同日排超了会警告，还有可选的「跨考试全局预算」校验。**计划是时间预算（分钟），和打卡数量是两层东西，界面上并排显示但不会相加。**
6. **薄弱项队列**：来自关联目标的知识点自评——待巩固的排前面，每条都有排序理由；点开复习卡可以直接再次自评。
7. **考前重点清单**：考前必须再过一遍的内容列表，勾掉只改清单状态，不影响任何评分。

## 七、我的页 —— 数据的保险箱

- **本地存储状态**：存储方式、最近一次成功写入时间、数据规模——全部真实，绝无「云端已同步」字样。
- **导出 JSON**：一键下载全部数据的备份文件（建议每周一次）。
- **导入 JSON**：先校验（版本、重复 ID、关联完整性）→ 展示摘要 → 选「合并」或「替换」→ 二次确认；导入前自动下载当前数据快照，失败不损坏现有数据。
- **清空示例 / 清空全部**：清空示例只删带「示例」标记的数据；清空全部需输入「清空」二字确认，不可恢复。
- **外观与个性化**：深色 / 浅色 / 跟随系统；今日页卡片显隐、信息密度（舒适/紧凑）；偏好只存本机。

## 八、数据安全与隐私（重要）

- **一切数据只在你手里**：网站版在浏览器 IndexedDB，Windows 在应用数据目录的 SQLite，Android 在应用私有目录。无服务器、无账号、无遥测。
- **风险提示**：浏览器版清浏览器数据 = 数据没了（所以导出 JSON）；Windows/Android **卸载应用**=数据没了（升级安装不受影响）。
- **三端不互通**：想换设备时，在旧设备「导出 JSON」→ 新设备「导入 JSON」。

## 九、常见问题

**Q：预计完成日显示「暂无推算」？** 近 7 天有打卡的日子不足 3 天，样本太少不猜。
**Q：打卡表单里的「分钟数」可以不填吗？** 可以。留空的记录参与完成率但不进分钟统计，应用绝不会替你编一个时长。
**Q：换了电脑/手机数据怎么迁？** 旧设备「我的 → 导出 JSON」→ 新设备「导入 JSON」→ 合并模式。
**Q：为什么专注 25 分钟没有让目标进度+1？** 因为应用坚持「时间≠完成量」——只有你如实填写的打卡数量才改变进度。
**Q：想恢复默认布局？** 我的 → 工作台个性化 → 恢复默认布局（不清数据）。

## 开发者

```bash
npm install && npm run dev    # 本地开发 http://localhost:5173
npm run test                  # 173 个测试
npm run build                 # 产出 dist/
npm run tauri build           # Windows 安装包（需 Rust+MSVC）
```

技术栈：React 18 + TypeScript（strict）+ Vite + Tailwind + Dexie(IndexedDB) / Tauri 2 + SQLite。测试 Vitest（时区无关、注入时钟）。构建产物由 GitHub Actions 自动产出。

docs/ 目录有架构、数据模型、各阶段扩展计划与测试报告。
